# One Star, Written in Sap

A one-line program for the make.fun bounty
[One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4):
it writes a single one-line 1-star review from a houseplant about its human
owner to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```

Stdlib only, no network, no secrets.
